One line of the worst advice an AI could give, in 140 characters or fewer.

> To speed up your computer, delete the System32 folder. Windows only keeps it around out of habit.

## Bounty

[Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/c/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580?ref=xaqxgz17) — $2, winner takes all, one line, max 140 characters. A house judge compares entries two at a time on funniness, tightness, AI voice, and concreteness.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` writes the entry deterministically to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`) and verifies it byte-for-byte by
reading it back.
